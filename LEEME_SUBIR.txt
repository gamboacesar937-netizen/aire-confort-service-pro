A&C SERVICE PRO 3.0 — ACTUALIZACIÓN PARA GITHUB PAGES
====================================================
1) ANTES DE ACTUALIZAR: abre la app 2.0 -> Ajustes -> Exportar respaldo JSON.
   Conserva el archivo en tu teléfono o almacenamiento privado.
2) CIERRA todas las pestañas anteriores de A&C Service Pro. Si hay otra pestaña
   abierta, la actualización de la base de datos IndexedDB puede bloquearse.
3) Abre tu repositorio github.com/gamboacesar937-netizen/aire-confort-service-pro
   y REEMPLAZA los archivos index.html y sw.js de la raíz con los de este ZIP.
   No crees una subcarpeta nueva para ellos. Confirma los cambios (Commit).
4) Abre https://gamboacesar937-netizen.github.io/aire-confort-service-pro/
   y actualiza la página. Puede requerir una segunda carga por el Service Worker.
5) Comprueba un reporte antiguo, una cotización y una orden nueva.

NOVEDADES: Agenda con calendario, órdenes de trabajo, asignaciones a técnicos,
directorio local de personal, panel de indicadores, exportación/restauración JSON v3.

SEGURIDAD Y ALCANCE: todos los registros siguen guardados localmente en la base
IndexedDB del mismo navegador y origen. No hay usuarios reales, permisos de acceso,
sincronización multi-dispositivo ni respaldo automático en la nube. GitHub Pages
solo publica el software, no almacena tus clientes. El directorio no crea cuentas.

INTEGRIDAD: el proyecto v3 reutiliza la base 'ayc_service_pro_v1' y migra
su esquema de v2 a v3, conservando reportes, inventario, cotizaciones y ajustes.
NO borres los datos de Chrome. Los importes del panel son valores registrados,
no cobros confirmados, y las cotizaciones no se cuentan como ingresos.
